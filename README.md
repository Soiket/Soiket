## About Me

I'm a **Cloud Engineer** specializing in infrastructure automation, virtualization, Kubernetes, and cloud-native technologies. I design, build, and maintain scalable infrastructure environments — from bare-metal server management to fully orchestrated Kubernetes clusters and private cloud platforms.

I believe that good infrastructure should be **invisible** — reliable, self-healing, and automated enough that teams can focus on building products instead of fighting systems.

> *Automate. Scale. Deploy. Repeat.*
